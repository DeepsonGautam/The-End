# THE END

A simple space survival game where you play as a fireball trying to survive against falling water enemies. The longer you survive, the harder the game gets.

---

## About The Game

In THE END, you are a fireball floating through space while water-like enemies fall from the sky. Your main goal is to survive as long as possible without touching the enemies.

If an enemy touches you, the game ends instantly.

As time passes:
- More enemies start spawning
- Enemy speed increases
- The game gradually becomes more difficult

The game also includes:
- A survival timer that tracks how long you stay alive
- A high score system to make the game more competitive and replayable

I tried to keep the game simple and fun instead of adding complicated mechanics.

---

## Controls

The controls are very simple:

- Left Arrow Key  -> Move Left
- Right Arrow Key -> Move Right

That’s all you need to play.

---

## Gameplay

- Start the game and survive as long as possible
- Dodge the falling enemies
- Stay focused as the game keeps getting harder over time
- Try to beat your highest survival time
